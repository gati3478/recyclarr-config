# Recyclarr Configuration for Whatbox + LG C1 + Sonos Beam 2

Opinionated Recyclarr config for a Direct Play-only Plex setup with specific hardware constraints.

## Hardware Context

- **Server**: Whatbox seedbox (no transcoding, Direct Play only)
- **Display**: LG C1 OLED (HDR10, Dolby Vision; no HDR10+)
- **Audio**: Sonos Beam 2 soundbar (Dolby Digital, DD+, Atmos; no DTS)
- **Client**: Plex on webOS

## Configuration Philosophy

One profile per resolution on each side — two Radarr profiles for movies, two Sonarr profiles for TV. Scores are explicit in the YAML, with one deliberate import: the guide's Unwanted formats group, adopted whole at its `-10000`, so a junk format the guide adds later arrives blocked rather than allowed. Explicit scores override it where this config disagrees, and `reset_unmatched_scores` zeroes everything else.

### Radarr Profiles

- **HD-Kino** (~6–16 GB): 1080p cap, premium WEB/BD groups, rich audio
- **UHD-Kino** (~20–35 GB): up to 2160p, HDR/DV, UHD BD/WEB top tiers, IMAX ok

### Sonarr Profiles

- **HD**: 1080p cap for TV series
- **UHD**: up to 2160p HDR/DV for prestige TV

## Key Design Decisions

**Audio**

- DTS blocked completely (hard `-10000`) — Beam 2 can't decode it, and Plex can't be allowed to transcode audio
- TrueHD scored positively despite incompatibility — releases usually include AC3/DD fallback tracks
- DD+ Atmos prioritized heavily — native Beam 2 support, excellent quality

**Video**

- HDR10+ mostly ignored (C1 doesn't support it; scored only as a tiebreaker)
- Dolby Vision preferred with HDR10 fallback required; DV-only blocked hard at every resolution — Plex on the C1 plays profile 5 only from MP4, and from MKV it shifts magenta — and so is DV or HDR10+ metadata generated by the groups the guide lists (Radarr)
- AV1 blocked — Plex on the C1 always transcodes it
- x265 penalized on 1080p releases without HDR (encoder-noise territory), lightly favored on UHD where it pairs with HDR

**Release Groups**

- TRaSH HQ tier formats (HD/UHD Bluray tiers, WEB tiers) applied in both services, scaled from TRaSH's 1600–1800 defaults down to +75…+200 — group quality breaks ties but never outvotes audio/HDR scoring

**Movie Versions (Radarr)**

- IMAX / IMAX Enhanced strongly preferred (+800); Hybrid, Open Matte, Criterion, Special Edition, and remasters get graded boosts; Theatrical Cut slightly penalized when a better version exists

**Universal Blocks & Nudges**

- Remux/BR-DISK blocked (too large; pointless for Direct Play)
- The guide's other unwanted formats blocked with it: releases tagged as upscales or regrades, black-and-white editions, and in Radarr 3D encodes, sing-along editions and line-dubbed audio
- Scene releases slightly penalized (prefer P2P quality)
- Low-quality and obfuscated releases heavily penalized; re-tags nudged down
- Repack/Proper scored +5…+7 as pure tiebreakers — grab the corrected release when otherwise equal

## Usage

1. Install [Recyclarr](https://recyclarr.dev/) (or use the Docker image)
2. Copy `recyclarr.yml` into recyclarr's config directory
3. Create a `secrets.yml` beside it with four keys — `radarr_url`, `radarr_api_key`, `sonarr_url`, `sonarr_api_key` — which the file references with `!secret`, so it names no URL or key itself
4. Preview, then apply:

```sh
recyclarr sync --preview
recyclarr sync
```

`tests/releases.tsv` pins the blocks and the audio, HDR, release-group, IMAX, cut, repack and x265 rules with release titles and what each profile must do with them, scored by Radarr's and Sonarr's own matcher (`tests/scores`, which assumes this setup's box).

## Why These Choices?

The scoring is opinionated toward a Direct Play workflow where file size matters but quality can't be sacrificed. One profile per resolution pursues the best release that still fits the size envelope (~6–16 GB at 1080p, ~20–35 GB at 2160p) — no 60 GB remuxes, no garbage compressions. The envelope is what the blocks and tiers yield, not a cap: the quality definition follows the guide's movie/series set, which sets no maximum. Everything respects the hard constraint: if Plex can't Direct Play it, it won't play at all.
